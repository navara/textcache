TextCache playground

Every scenario writes a text that starts with a marker TC-<run>-<scenario>. Press Run all, wait for #runState to say done, then search the extension's full list for TC-<run> and compare with the table at the bottom. Each field can also be typed into by hand. Run code:

idle

1. Text area

Saved, kind text.

2. Single-line input

Never saved.

3. Rich-text editor with nested markup

One saved text, kind html, for the whole editor.

4. Text area inside an open shadow root

Saved.

5. Text area inside a srcdoc frame

Saved; its address is about:srcdoc.

6. Text area added after the page loaded

Saved.

7. Editor that the page rebuilds while you type

The page replaces the editor element with a copy after every change, as some chat apps do. One saved text holding the final content; not one per rebuild.

8. The same text in two fields

With "remove older copies of the same text" on: one saved text. With it off: two.

9. A text over the size limit

With the default limit of 1024 KB: the short first version stays saved, the 2 MB version is not, the toolbar icon shows MAX on this tab.

10. Only spaces and line breaks

Never saved.

11. Editor cleared and rebuilt after sending

The page sends the message and replaces the editor with an empty one, as chat apps do; then a different message is typed. Two saved texts: the sent message is not overwritten by the next one.
